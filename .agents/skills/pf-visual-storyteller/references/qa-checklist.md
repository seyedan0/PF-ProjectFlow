# Visual Quality Assurance Checklist

Before finalizing any SVG, Canvas layout, or visual prompt, verify:
- [ ] **Single Core Idea**: Can a developer grasp the core architectural point in under 5 seconds?
- [ ] **No Text Clipping**: Are all labels under 4 words, with sufficient padding inside their containers?
- [ ] **Semantic Color Honesty**: Is Rose (`#F43F5E`) used ONLY for errors/drift/boundaries and Emerald (`#10B981`) ONLY for valid/active states?
- [ ] **Directional Clarity**: Does the eye naturally flow Left-to-Right (`LTR`) or Top-to-Bottom (`TTB`) without criss-crossing spaghetti lines?
- [ ] **Metaphor Integrity**: Does the visual show *how* the mechanism works rather than just listing component names?
